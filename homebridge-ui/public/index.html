Your configuration is using the legacy input format. Migrate to the new format to enable drag & drop reordering in the Homebridge Config UI.

Input Configuration Migration

This tool migrates your input configuration from the legacy input1-input16 format to the new inputs array format, which enables drag & drop reordering in the Homebridge UI.

What does migration do?
  • Converts input1, input2, etc. to the new inputs array format
  • Preserves all your custom input labels and enabled/disabled states
  • Enables drag & drop reordering in the Homebridge Config UI
  • Automatically removes invalid or malformed input configurations
Note: After migration, you must restart Homebridge for changes to take effect.
